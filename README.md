# DriveVault for Easy Digital Downloads

Seamlessly attach and serve Easy Digital Downloads digital files directly from Google Drive with high-performance secure streaming downloads.

## Features

- **Direct Google Drive Integration**: Authenticate via Google OAuth 2.0.
- **Modern React File Picker**: Search and select files directly from Easy Digital Downloads edit screens.
- **High-Performance Chunked Streaming**: Secure memory-safe downloads with HTTP Range/Resume support.
- **Shared Drive Support**: Full support for Google Workspace Team / Shared Drives.
- **Easy Digital Downloads 3.x Compatible**: Built natively for EDD 3.x download files and logging.
- **Transients Caching**: Fast folder traversal and storage quota overview with skeleton loading.

## Development

```bash
# Install dependencies
npm install

# Start development watcher
npm start

# Build production assets
npm run build

# Create production release zip
npm run build:prod
```
